Can a later event decide what a network remembers?

In the brain, a fresh memory is fragile. It leaves a temporary tag, and it becomes permanent only if a salient event supplies plasticity-related products while the tag is still there. This lab shows the same mechanism working inside a neural network trained with backpropagation, using results from real training runs.

1. Move the salient event

A network learns a hard digit task (3 vs 5) weakly, for 60 steps. One salient event happens somewhere in time. After a long delay, only what was consolidated is left. Slide the event and watch the tag, the plasticity-related products and the capture.

2. A new, surprising task rescues an older one

Now the salient event is the start of a new task B. Its onset rescues task A retroactively, but only while A's tags last. If tags belong to the weight, B's own learning re-tags the same weights and rescues A far too late. If tags belong to the change, the window is clean.

4. Does it prevent forgetting?

On Split-MNIST, a standard benchmark of five digit tasks in a row, consolidation alone does not stop forgetting: consolidated weights are not protected from later learning. Using the consolidation record as the importance signal for protecting weights helps about as much as Elastic Weight Consolidation, though less than Synaptic Intelligence. The difference is that importance is chosen by salient moments after the fact, not fixed at the time of learning. When each task has its own output head, every method is close to the ceiling.
